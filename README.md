# Steam Deck EXE Multitool

Утилита для упрощенного запуска Windows-приложений (.exe) и установщиков (setup.exe) на Steam Deck с автоматическим созданием скриптов-оберток.

## Возможности

*   **Запуск Setup.exe**: Удобная установка игр через Proton.
*   **Авто-создание .sh скриптов**: После выбора или установки игры, в папке `/home/deck/Downloads` создается файл `[название].exe.sh`.
*   **Управление префиксами**: Для каждой игры создается свой изолированный префикс в `compatdata`, что предотвращает конфликты зависимостей.
*   **Выбор Proton**: Возможность выбрать конкретную версию Proton, установленную в системе.

## Как использовать

1.  Скачайте `multitool.sh` на ваш Steam Deck.
2.  Сделайте файл исполняемым: `chmod +x multitool.sh`.
3.  Запустите скрипт: `./multitool.sh`.
4.  Следуйте инструкциям в графическом интерфейсе (Zenity).

## Принцип работы

Скрипт использует переменные окружения Steam для запуска Proton вне клиента Steam:
*   `STEAM_COMPAT_CLIENT_INSTALL_PATH` — путь к Steam.
*   `STEAM_COMPAT_DATA_PATH` — путь к Wine-префиксу (папка `compatdata`).

После добавления игры или завершения установки, мультитул генерирует shell-скрипт, который сохраняет все настройки совместимости, позволяя запускать игру одним кликом из рабочего стола или добавлять этот `.sh` файл в Steam как "Non-Steam Game".

## Требования

*   Steam Deck (SteamOS).
*   Установленный Proton (через Steam).
*   Zenity (предустановлен в SteamOS).
